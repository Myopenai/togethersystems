## 🚀 Verwendung

### Windows
1. ZIP entpacken
2. Doppelklick auf `run.bat`

### Linux / macOS / Raspberry Pi
1. ZIP entpacken
2. Terminal öffnen im entpackten Ordner
3. `chmod +x run.sh`
4. `./run.sh`

Der Browser öffnet sich automatisch auf `http://127.0.0.1:9090`
