🎯 Einführung

Together Systems ist ein Meta-Transaktionsportal, in dem Sie: - Ohne Registrierung arbeiten können - Automatisch identifiziert werden (pro Browser) - In Räumen miteinander kommunizieren - Verträge und Vouchers als JSON-Objekte austauschen - Echte Geschäfte abwickeln können Kein Login, kein Passwort, keine E-Mail-Registrierung! ---

🚀 Portal Start

Was ist das Portal Start?

Die Einstiegsseite für alle User. Hier finden Sie: - Übersicht aller verfügbaren Features - Download-Link für Manifest-Forum - Navigation zu allen Applikationen - Hilfe & Dokumentation

Wie nutze ich es?

1. Öffnen Sie `index.html` im Browser 2. Sie sehen alle verfügbaren Features 3. Klicken Sie auf "Manifest-Forum herunterladen" (wenn Sie offline arbeiten möchten) 4. Oder klicken Sie auf "Portal öffnen" (für Online-Zugang)

Was kann ich hier machen?

- ✅ Alle Features entdecken - ✅ Manifest-Forum herunterladen - ✅ Zu Online-Portal wechseln - ✅ Hilfe-Seiten öffnen - ✅ Alle Applikationen erreichen ---

📝 Manifest-Forum

Was ist das Manifest-Forum?

Ein offline-Forum für Beiträge, Gedanken und Analysen. Funktioniert komplett offline im Browser.

Wie nutze ich es?

1. Laden Sie `manifest-forum.html` herunter 2. Speichern Sie die Datei auf Ihrem Computer 3. Öffnen Sie die Datei im Browser (Doppelklick) 4. Erstellen Sie Beiträge mit: - Titel: Kurze Überschrift - Inhalt: Ihr Text, Gedanken, Analysen - Tags: Kommagetrennt (z.B. "chaos, ordnung, universum") - Medien: Bilder, Videos, Audio hinzufügen - Initialen: Ihre Initialen (z.B. "RDT") - Logo: Optional Logo hinzufügen

Was kann ich hier machen?

- ✅ Beiträge erstellen (offline) - ✅ Bilder, Videos, Audio hinzufügen - ✅ Beiträge lokal speichern - ✅ Exportieren als JSON - ✅ Online-Portal öffnen (mit Verifizierung)

Wichtige Funktionen:

- Export: Alle Daten als JSON exportieren - Import: JSON-Daten importieren - Portal öffnen: Automatisch verifiziert zum Online-Portal - Lokale Speicherung: Alles bleibt auf Ihrem Computer ---

🌐 Online-Portal

Was ist das Online-Portal?

Die Online-Brücke zum Manifest-Forum. Hier können Sie: - Feed mit allen Beiträgen sehen - Live-Chat nutzen - Vouchers erstellen - Events verwalten - Immobilien & Hypotheken verwalten

Wie nutze ich es?

1. Kommen Sie vom Manifest-Forum (automatisch verifiziert) 2. Oder geben Sie Token manuell ein 3. Sie sehen den Feed mit allen Beiträgen 4. Nutzen Sie Live-Chat für Kommunikation 5. Erstellen Sie Vouchers für Transaktionen

Was kann ich hier machen?

- ✅ Feed mit allen Beiträgen sehen - ✅ Live-Chat nutzen - ✅ Vouchers erstellen - ✅ Events verwalten - ✅ Immobilien & Hypotheken verwalten - ✅ Termine verwalten

Wichtige Funktionen:

- Verifizierung: Automatisch vom Manifest-Forum oder manuell - Feed: Alle Beiträge im Überblick - Live-Chat: Echtzeit-Kommunikation - Vouchers: Transaktions-Objekte erstellen - Events: Veranstaltungen verwalten ---

🍯 Wabenräume

Was sind Wabenräume?

Visuelle Raumlogik für Transaktionen, Events und Produkte. Jeder Raum (A-1, B-2, etc.) kann verschiedenen Zwecken zugeordnet werden.

Wie nutze ich es?

1. Öffnen Sie `honeycomb.html` 2. Wählen Sie einen Raum (z.B. A-1) 3. Ordnen Sie Transaktionen oder Events zu 4. Nutzen Sie Raum für Verhandlungen

Was kann ich hier machen?

- ✅ Räume auswählen - ✅ Transaktionen zuordnen - ✅ Events zuordnen - ✅ Produkte zuordnen - ✅ Verhandlungen führen ---

❓ Häufige Fragen

Wie starte ich?

1. Öffnen Sie `index.html` 2. Laden Sie Manifest-Forum herunter 3. Erstellen Sie Beiträge 4. Öffnen Sie Online-Portal

Brauche ich ein Konto?

Nein! Kein Login, kein Passwort, keine E-Mail-Registrierung. Sie werden automatisch pro Browser identifiziert.

Wo werden meine Daten gespeichert?

- Offline: Im Browser (localStorage) - Online: Optional auf Server (wenn Sie das wünschen)

Was ist der Unterschied zwischen Manifest-Forum und Online-Portal?

- Manifest-Forum: Offline, lokal im Browser - Online-Portal: Online, mit Live-Features (Chat, etc.)

Wie funktioniert die Verifizierung?

Automatisch vom Manifest-Forum zum Online-Portal. Oder manuell mit Token.

Was ist ein Voucher?

Ein Transaktions-Objekt (JSON) für Geschäfte, Verträge, Termine, etc.

Was sind Wabenräume?

Visuelle Raumlogik für Transaktionen, Events und Produkte.

Wie nutze ich TELBANK?

1. Verbinden Sie MetaMask 2. Führen Sie Transfers durch 3. Sehen Sie Historie

Was ist Settings OS?

Ein vollständiges Settings-System für alle Projekte.

Was ist das CMS Dashboard?

Ein Content Management System für Websites (besser als JouwWeb).
