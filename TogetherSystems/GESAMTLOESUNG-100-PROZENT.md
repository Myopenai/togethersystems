## 🔄 WORKFLOW

### 1. Code-Änderung
- File-Watcher erkennt Änderung
- Trigger: `watch-and-patch.sh`

### 2. Error Event Processing
- Konsolen-Events werden erfasst
- Error Bus klassifiziert
- AI-Fixer generiert Patch
- Patch wird angewendet
- Verifikation läuft

### 3. Dokumentation Update
- Auto-Doc-Updater sammelt Änderungen
- Generiert neue Docs aus Templates
- Erstellt History-Snapshot (append-only)
- Signiert & attestiert

### 4. Deploy
- Nur wenn alle Gates passiert
- Ethics-Pass erforderlich
- Signatur & Attestierung erforderlich
