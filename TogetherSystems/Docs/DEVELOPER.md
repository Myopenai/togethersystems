## 🚀 Schnellstart

### 1. Repository klonen

```bash
git clone https://github.com/togethersystems/togethersystems.git
cd togethersystems/TogetherSystems
```

### 2. Dependencies installieren

```bash
npm install
```

### 3. A-Start ausführen

```bash
cd Fabrikage.AutoExecution/bootstrap
npm run a-start
```
