## 📦 Produktbeschreibung

Die Fabrikage ist eine **digitale Produktionsfabrik**, die alle Schritte der Softwareentwicklung und -bereitstellung automatisiert.

### Kernkomponenten

#### 1. AI-Code-Maschine

- Generiert fehlerfreien Code **just-in-time**
- Unterstützt alle gängigen Programmiersprachen
- Integriert mit Cursor.com, ChatGPT, DeepSeek, Claude und vielen weiteren AI-Modulen

#### 2. Konsolen-Integration (Herz-Bypass)

- **Debug:** Stderr, Exceptions, Stacktraces
- **Problems:** Compiler, Linter, Typecheck
- **Output:** App-Logs, Performance-Logs
- **Terminal:** Process-Exit, Signals, Retries
- **Ports:** Bind-Fail, Conflicts, Timeouts
- **Playwright:** Test-Fail, Accessibility-Violations, Contrast-Ratio

**Prinzip:** Konsolen sind nicht nur Beobachter, sondern Bypass: Fehler → direkt in AI-Generator → Korrektur → zurück ins Build. Kein Stop, sondern kontinuierlicher Blutfluss wie im Herz.

#### 3. Auto-Fixer

- **Syntax-Fixer:** SyntaxError, TypeError, MissingSemicolon, UndefinedVariable
- **Runtime-Fixer:** NullReference, Timeout, UnhandledPromise
- **Port-Fixer:** EADDRINUSE, BindError, PortConflict
- **Accessibility-Fixer:** ContrastViolation, MissingARIA, FocusableError
- **Playwright-Fixer:** TestFail, SelectorNotFound, TimingIssue

**Ergebnis:** Fehler werden sofort erkannt und korrigiert, **ohne Produktionsstopp**.

#### 4. Self-Healing Runtime

- **Kill-Switches:** Kritische Komponenten sofort abschaltbar
- **Feature-Flags:** Automatisches Stoppen fehlerhafter Teilpfade
- **Atomare Rollbacks:** Rückkehr zu letztem "grünen" Zustand ohne Residuen
- **Staged Rollouts:** Canary/Blue-Green mit SLO-Wächtern

#### 5. Append-only Dokumentation

- **Automatische Generierung:** Jede Änderung wird automatisch dokumentiert
- **Signatur & Attestierung:** RSA-4096 Signaturen, Provenance Ledger
- **Historische Nachvollziehbarkeit:** Alle Snapshots bleiben erhalten
- **Verifizierung:** Jede Doku wird signiert und attestiert

#### 6. Push-Up-Updates

- **Automatische Updates:** Originalproduzent liefert Updates direkt
- **Partner-Entscheidung:** Akzeptieren, Negieren oder Weiterveräußern
- **Registrierung:** Systeme registrieren Updates und informieren Betreiber
