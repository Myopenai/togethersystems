## 🚀 Schnellstart

1. **A-Start aktivieren:**
   ```bash
   cd Fabrikage.AutoExecution/bootstrap
   npm run a-start
   ```

2. **Manifest laden:**
   ```bash
   cat factory.manifest.yaml
   ```

3. **Pipeline ausführen:**
   ```bash
   cd Pipelines
   npm run build
   ```
