## 📋 CSV-IMPORT FUNKTIONALITÄT

### Verwendung:
1. **CSV-Datei wählen** → Button klicken
2. **CSV-Datei auswählen** → Datei-Dialog
3. **Importieren** → Button klicken
4. **Erfolg** → Kontakte werden in localStorage gespeichert

### CSV-Format:
```
Name,Email,Telefon
Max Mustermann,max@example.com,0123456789
Anna Schmidt,anna@example.com,0987654321
```

### Speicherung:
- Kontakte werden in `localStorage.contacts` gespeichert
- Format: JSON Array von Kontakt-Objekten
- Automatische Zusammenführung mit bestehenden Kontakten
