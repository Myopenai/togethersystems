# 🚀 SERVER STARTEN - EINFACHE ANLEITUNG

## ✅ SERVER AUSFÜHREN:

### Option 1: Doppelklick (Einfachste Methode)
**Doppelklick auf:**
- `START-SERVER.bat` - Server im Terminal-Fenster
- `START-SERVER-HINTERGRUND.bat` - Server im Hintergrund

### Option 2: Direkt
**Doppelklick auf:**
- `builds\go-executable\ostosos-server.exe`

### Option 3: Terminal
```powershell
cd builds\go-executable
.\ostosos-server.exe
```

---

## 📋 ERSTELLTE DATEIEN:

✅ `START-SERVER.bat` - Startet Server im Terminal
✅ `START-SERVER-HINTERGRUND.bat` - Startet Server im Hintergrund

## 🌐 NACH DEM START:

**Server läuft auf:** `http://localhost:8080`

**Im Browser öffnen:**
- Öffne Browser
- Gehe zu: `http://localhost:8080`

---

## ⏹️ SERVER BEENDEN:

- **Im Terminal:** Drücke `Ctrl+C`
- **Im Hintergrund:** Task-Manager → `ostosos-server.exe` beenden
