# 🔴 STANDARD: Markdown zu HTML Konvertierung

**Status:** PERMANENT AKTIV - Immer verwenden wenn User alle .md zu .html konvertiert haben möchte  
**Erstellt:** 2025-01-XX  
**Wichtigkeit:** HOCHST

---

## 🎯 WANN ANWENDEN

**IMMER wenn User möchte:**
- Alle Markdown-Dateien zu HTML konvertieren
- Klickbare Navigation zwischen Dokumentationen
- Index-Seite mit Suche
- Browser-optimierte Anzeige ohne CORS-Probleme

**Prinzip:** Minimale Handlungen - Maximale Ergebnisse

---

## 📁 ZU ERSTELLENDE DATEIEN

### 1. PowerShell-Script
**Name:** `KONVERTIERE-ALLE-zu-HTML-COMPLETE.ps1`

**Features:**
- Findet ALLE .md Dateien rekursiv
- Konvertiert jede zu vollständiger HTML-Datei
- Erstellt Index-Seite: `DOKU-INDEX-ALL.html`
- Kategorisiert (Handbücher, Tests, Anleitungen, etc.)
- Suchfunktion
- Navigation zwischen Dokumentationen
- Statistiken

### 2. Batch-Datei
**Name:** `KONVERTIERE-ALLE-COMPLETE.bat`

**Features:**
- Ein Klick zum Starten
- Zeigt Fortschritt
- User-freundlich

### 3. Anleitung
**Name:** `ANLEITUNG-ALLE-HTML-COMPLETE.txt`

**Features:**
- Schritt-für-Schritt
- Alle Features erklärt

---

## ✅ HTML-STANDARDS

Jede HTML-Datei muss haben:
- Vollständige HTML-Struktur
- Responsive Design
- Navigation
- Zurück-Button
- Link zur Index-Seite
- Code-Syntax-Highlighting
- Tabellen, Bilder, Links Support

---

## 📚 INDEX-SEITE

**Pflicht:** `DOKU-INDEX-ALL.html`

**Enthält:**
- Alle Dokumentationen
- Kategorisiert
- Suchfunktion
- Klickbare Links
- Statistiken

## 🔄 SOFORT ANWENDEN

1. Kopiere Template aus `Settings/templates/md-to-html-converter/`
2. Erstelle Scripts wie beschrieben
3. User doppelklickt auf `.bat` Datei
4. Fertig!
