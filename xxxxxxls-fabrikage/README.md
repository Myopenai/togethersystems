## 🔌 API ENDPOINTS

### GET Endpoints

- `/api/nodes` - Alle Knoten
- `/api/links` - Alle Verbindungen
- `/api/events` - Event-Log
- `/api/energy-ledger` - Energie-Ledger
- `/api/universal/layers` - Universal-Layer
- `/api/health` - System Health

### POST Endpoints

- `/api/morph` - Module transformieren
  ```json
  {
    "action": "replicate",
    "target": "N-PLANT-A",
    "morphType": "assembly"
  }
  ```

- `/api/nodes` - Neuen Knoten erstellen
  ```json
  {
    "id": "N-NEW",
    "level": "META",
    "ports": ["material", "energy", "info"],
    "holoState": "new-vector"
  }
  ```
