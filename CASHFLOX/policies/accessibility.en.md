# Accessibility — Policy (EN)

Goals:
- Keyboard operability, sufficient contrast, scalable type.
- Provide alternative text and meaningful ARIA roles.
- No UI change here; this serves as a checklist for implementations.

Checks (excerpt):
- Logical focus order, visible focus indicator.
- Semantics: heading structure, form labels, landmarks.
- Color: WCAG 2.1 AA contrast conformity.
