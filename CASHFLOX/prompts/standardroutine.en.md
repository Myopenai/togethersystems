# Standard Routine — Prompts (EN)

Goal: Run the production pipeline deterministically — without changing the UI.

Core principle:
- Recognize → Validate → Produce

Guide prompts:
1. Pre-Analysis  
   - Assess complexity, dependencies, risks.  
   - Standardize inputs (formats, paths).
2. Tracking  
   - Log session ID, artifacts, status events.  
   - Maintain visibility/transparency.
3. Implementation  
   - Respect policies (Security, Accessibility).  
   - No UI modifications to `chflox.html`.
4. Verification  
   - Gates: Contracts/Schema, Tests, Compliance, Build, Report.
5. Report  
   - KPIs, logs, traces, hashes (STAMP-SHA256).
