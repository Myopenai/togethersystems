2) VORAUSSETZUNGEN & SETUP
- OS: Windows 10/11, macOS 12+, Linux (Ubuntu 22.04+/Debian 11+)
- Software: Python 3.10+, Node.js 20+, PowerShell 7+/Bash, Git 2.30+, (optional) Go 1.21+
- Minimaler Einstieg (lokal, ohne Build):
  - Öffnen Sie lokal: index.html (leitet auf die Single-File-App)
  - Single-File-App: „WHD Applikation — Komplettes Single-File System TTT.html“

3) KERNMODULE-INSTALLATION
- CoreProtocols: Policies (z. B. accessibility.yaml, security.yaml) verwalten; YAML-Schema validieren.
- AutoExecution: Scripts & Pipelines (z. B. deploy-standardroutine.ps1) für Deploy-Strategien.
- PromptProcessing: Prompt-Tracker, Pipeline-Orchestrierung, Pre-Analysis, Verifier, Code-Visibility.
- IntelligenceMatrix: Policy-Executors, Optimizer, Self-Healing-Strukturen vorbereiten.
- ProvenanceLedger: SBOM/Signaturen/Attestations-Struktur.
- ObservabilityAtlas: metrics/logs/traces/reports-Verzeichnisse.

4) FLIEßBAND-SYSTEM (A-Start)
- Prinzip: Recognize → Validate → Produce
- A-Start lädt „factory.manifest.yaml“, prüft Policies/Schemata und produziert Artefakte mittels Generatoren.
- Deterministisch, deklarativ, wiederholbar.

5) PROMPT-GENERATOR & USER-ARBEITSPLATZ
- Workflow: User-Prompt → Pre-Analysis → Tracking → Implementierung → Verifikation → Report
- Komponenten:
  - Prompt-Tracker (Sessions, Multi-Dimensions)
  - Prompt-Pipeline (Orchestrierung/Status)
  - Pre-Analysis (Komplexität, Abhängigkeiten, Risiko)
  - Prompt-Verifier (Ergebnisprüfung)
  - Code-Visibility-Manager (Sichtbarkeit/Transparenz)

6) ARBEITSPLÄTZE
- Prompt-Arbeitsplatz: automatisierte Eingabe/Validierung/Verfolgung
- Code-Arbeitsplatz: Generierung/Build/Index
- Test-Arbeitsplatz: Unit/Integration/E2E + Metriken & Reports
- Verifikations-Arbeitsplatz: SBOM/Signaturen/Attestations
- Optimierungs-Arbeitsplatz: Performance, Self-Healing, Policy-Execution

7) PRODUKTIONSPIPELINE
- Phasen:
  1. Pre-Deploy: Root-Ordner-Tests, TÜV-Test 3×
  2. Deploy: Multi-Server-Deployment, Fehlerbehandlung
  3. Post-Deploy: erneute Root-Tests, TÜV-Test 3×
  4. Freigabe: Offizielle Signatur, Freigabe-Dokumentation
