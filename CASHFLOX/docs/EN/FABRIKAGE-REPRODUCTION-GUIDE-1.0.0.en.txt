2) PREREQUISITES & SETUP
- OS: Windows 10/11, macOS 12+, Linux (Ubuntu 22.04+/Debian 11+)
- Software: Python 3.10+, Node.js 20+, PowerShell 7+/Bash, Git 2.30+, (optional) Go 1.21+
- Minimal start (local, no build):
  - Open locally: index.html (redirects to single-file app)

3) CORE MODULES INSTALLATION
- CoreProtocols: manage policies (e.g., accessibility.yaml, security.yaml); validate YAML schemas.
- AutoExecution: scripts & pipelines (e.g., deploy-standardroutine.ps1) for deployment strategies.
- PromptProcessing: prompt tracker, pipeline orchestration, pre-analysis, verifier, code visibility.
- IntelligenceMatrix: policy executors, optimizer, prepare self-healing structures.
- ProvenanceLedger: structure for SBOM/signatures/attestations.
- ObservabilityAtlas: directories for metrics/logs/traces/reports.

4) ASSEMBLY LINE SYSTEM (A-START)
- Principle: Recognize → Validate → Produce
- A-Start loads “factory.manifest.yaml”, validates policies/schemas, and produces artifacts via generators.
- Deterministic, declarative, repeatable.

5) PROMPT GENERATOR & USER WORKSPACE
- Workflow: User Prompt → Pre-Analysis → Tracking → Implementation → Verification → Report
- Components:
  - Prompt Tracker (sessions, multi-dimensions)
  - Prompt Pipeline (orchestration/status)
  - Pre-Analysis (complexity, dependencies, risk)
  - Prompt Verifier (result validation)
  - Code Visibility Manager (visibility/transparency)

6) WORKSTATIONS
- Prompt workstation: automated input/validation/tracking
- Code workstation: generation/build/indexing
- Test workstation: unit/integration/E2E + metrics & reports
- Verification workstation: SBOM/signatures/attestations
- Optimization workstation: performance, self-healing, policy execution
