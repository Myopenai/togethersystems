## 🚀 Schnellstart

### Portable Version (Empfohlen)

1. Laden Sie das Portable Package herunter
2. Entpacken Sie die ZIP-Datei
3. Öffnen Sie `index.html` in Ihrem Browser
4. Fertig! Keine Installation erforderlich.

### Desktop-App (Electron)

#### Voraussetzungen

- Node.js 18+ installiert
- npm installiert

#### Installation

```bash
# Dependencies installieren
npm install

# App starten
npm start

# Für alle Plattformen bauen
npm run build:all

# Nur für Windows
npm run build:win

# Nur für macOS
npm run build:mac

# Nur für Linux
npm run build:linux
```

### PWA (Progressive Web App)

1. Öffnen Sie `index.html` in Chrome/Edge
2. Klicken Sie auf "Installieren" im Browser-Menü
3. Die App wird als Desktop-App installiert

## 🎯 Features

- ✅ **Alle Apps in einem System**
  - Kassenbuch
  - Budget (DaVinci Sphere)
  - Contract
  - Flowcashx
  - UAE / Chflox

- ✅ **Automatische Synchronisation**
  - Alle Apps kommunizieren automatisch
  - Daten werden in Echtzeit synchronisiert
  - Cross-Tab Kommunikation

- ✅ **Plattformübergreifend**
  - Funktioniert auf allen Geräten
  - Keine Installation erforderlich (Portable)
  - Electron-App für Desktop
  - PWA für Mobile/Web

- ✅ **Offline-Funktionalität**
  - Service Worker für Caching
  - Funktioniert ohne Internet
  - Daten werden lokal gespeichert
