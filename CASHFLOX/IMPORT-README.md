# External Imports Guide

Purpose: Bring existing documents/folders into this repository without changing the UI.

Suggested target: `docs/EXTERNAL-IMPORTS/`

Windows steps:
1. Open File Explorer.
2. Navigate to your source folder, e.g.:  
   `D:\busineshuboffline CHATGTP\TOGETHERSYSTEMS- GITHUB\Nieuwe map (3)`
3. Copy the desired files/folders (.js, .md, .txt, documentation assets).
4. Paste into this repository under:  
   `C:\Users\Gebruiker\Documents\01db.com\CASHFLOX\docs\EXTERNAL-IMPORTS\`

Notes:
- Keep the UI intact; do not alter `chflox.html`.
- Prefer plain-text formats (.md, .txt) over binary when possible.
- After import, update language READMEs to link to the new materials.
