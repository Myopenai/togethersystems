## 🚀 Schnellstart

### Für Dummies (Einfachste Methode):

1. **Doppelklick** auf: `tests\think-orders\run-tests.ps1`
2. **Fertig!** Script führt alles automatisch aus

### Schritt-für-Schritt:

1. **Lesen:** `tests\think-orders\START-HIER-DUMMIES.md`
2. **Terminal öffnen** (Windows-Taste → PowerShell)
3. **Zum Ordner wechseln:**
   ```powershell
   cd "tests\think-orders"
   ```
4. **Installieren:**
   ```powershell
   npm install
   npx playwright install
   ```
5. **Tests ausführen:**
   ```powershell
   npm test
   ```

**→ Siehe `tests\think-orders\HANDBUCH-DE-KOMPLETT.md` für vollständige Anleitung!**
