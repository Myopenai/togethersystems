Q: Wo sind meine Daten gespeichert?

A: In Ihrem Browser (localStorage). - Windows: C:\Users\[IhrName]\AppData\Local\[Browser]\... - Aber Sie müssen die Daten nicht manuell suchen! - Verwenden Sie die Export-Funktion zum Sichern!

Q: Kann ich die Datei auf einem anderen Computer verwenden?

A: Ja! 1. Kopieren Sie die Datei `THYNK-ORDERS-COMPLETE.html` 2. Kopieren Sie auch Ihre Backup-Datei 3. Auf dem anderen Computer: - Öffnen Sie die HTML-Datei - Importieren Sie die Backup-Datei - Fertig!

Q: Verliere ich Daten beim Browser-Wechsel?

A: Ja, aber Sie können sie übertragen! 1. Vor dem Wechsel: Exportieren Sie alle Daten 2. Neuer Browser: Öffnen Sie die HTML-Datei 3. Importieren: Laden Sie die exportierten Daten 4. Fertig!

Q: Funktioniert es ohne Internet?

A: Ja! - Nach dem ersten Öffnen benötigen Sie kein Internet - Alles läuft lokal auf Ihrem Computer - Nur beim ersten Öffnen wird der Browser geladen

Q: Kann ich mehrere Benutzer haben?

A: Aktuell nicht automatisch. - Aber: Jeder Computer/Browser hat eigene Daten - Oder: Exportieren Sie Daten und teilen Sie sie

Q: Was bedeutet "pending", "paid", etc.?

A: Das sind Status-Begriffe: - pending = ausstehend (noch nicht bezahlt) - paid = bezahlt - shipped = versendet - cancelled = storniert ---
