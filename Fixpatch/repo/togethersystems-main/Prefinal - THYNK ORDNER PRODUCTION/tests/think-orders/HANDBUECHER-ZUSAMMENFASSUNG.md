### Methode 1: Doppelklick (Einfachste)

1. **Doppelklick** auf `run-tests.ps1`
2. **Fertig!** Script führt alles aus

### Methode 2: Terminal (Manuell)

```powershell
cd tests\think-orders
npm install
npx playwright install
```
