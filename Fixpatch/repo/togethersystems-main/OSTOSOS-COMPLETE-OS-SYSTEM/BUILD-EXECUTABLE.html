Build für alle Plattformen:

Windows (.exe):

```bash cd OSTOSOS-COMPLETE-OS-SYSTEM GOOS=windows GOARCH=amd64 go build -ldflags="-s -w" -o OSTOSOS-Setup.exe OSTOSOS-SETUP.go ```

macOS (.app):

```bash cd OSTOSOS-COMPLETE-OS-SYSTEM GOOS=darwin GOARCH=amd64 go build -ldflags="-s -w" -o OSTOSOS-Setup.app OSTOSOS-SETUP.go ```

Linux (.bin):

```bash cd OSTOSOS-COMPLETE-OS-SYSTEM GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o OSTOSOS-Setup.bin OSTOSOS-SETUP.go ```
