```
    │   └── OSTOSOS-Setup.exe
    ├── macOS/
    │   └── OSTOSOS-Setup.app
    ├── Linux/

    ├── Universal/

```

### Build-Ausführung:

**PowerShell (Windows):**
```powershell
cd OSTOSOS-COMPLETE-OS-SYSTEM
.\build-all-platforms.ps1
```

**Bash (macOS/Linux):**
```bash
cd OSTOSOS-COMPLETE-OS-SYSTEM
chmod +x build-all-platforms.sh
./build-all-platforms.sh
```
