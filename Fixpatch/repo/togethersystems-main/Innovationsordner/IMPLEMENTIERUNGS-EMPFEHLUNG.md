**Kombination:**
1. **Transformers.js (Offline)** - Standard, schnell, keine Installation
2. **Online APIs (Optional)** - Bessere Qualität wenn verfügbar
3. **User-Wahl** - User kann zwischen Offline/Online wählen

**Warum diese Lösung:**
- ✅ Funktioniert immer (Offline als Fallback)
- ✅ Beste Qualität wenn Online verfügbar
- ✅ Keine Installation nötig
- ✅ User hat Kontrolle
- ✅ Schnellste Implementierung

**Modell-Empfehlung:**
