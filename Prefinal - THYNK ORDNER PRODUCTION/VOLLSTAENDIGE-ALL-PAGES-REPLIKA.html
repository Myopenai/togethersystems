Mit Original CSS:

🔄 Workflows

Workflow 1: Produkt → Bestellung → Rechnung

1. Produkt hinzufügen (`/#/products`) - Klicke "➕ Add Product" - Eingabe: Name, Price, SKU 2. Bestellung erstellen (`/#/orders/new`) - Produkt zum Warenkorb hinzufügen - Kundendaten eingeben - Bestellung erstellen 3. Bestellung bezahlen (`/#/orders`) - Status ändern auf "paid" - Rechnung wird automatisch erstellt!

Workflow 2: Daten sichern

1. Backup erstellen (`/#/settings`) - Klicke "💾 Backup" - JSON-Datei wird heruntergeladen 2. Backup wiederherstellen (`/#/settings`) - Klicke "📥 Restore" - Wähle JSON-Datei - Daten werden importiert ---
