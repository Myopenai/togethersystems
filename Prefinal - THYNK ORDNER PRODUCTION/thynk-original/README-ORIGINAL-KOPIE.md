## 📋 EXTRAKTIONS-ANLEITUNG

### Schritt 1: Einloggen
1. Öffnen Sie: **https://thynkorders.com/#/sign-in**
2. Username: **Gentlyoverdone**
3. Password: **WebMaster8/**
4. Einloggen

### Schritt 2: Browser-Konsole öffnen
1. Drücken Sie **F12**
2. Gehen Sie zum Tab **"Console"**

### Schritt 3: HTML-Quellcode extrahieren
1. Öffnen Sie: `scripts/extract-complete-html-source.js`
2. Kopieren Sie den Inhalt
3. Fügen Sie in die Browser-Konsole ein
4. Ausführen: `extractCompleteHTMLSource()`
5. ✅ Kompletter HTML-Quellcode wird heruntergeladen

### Schritt 4: Alle Assets downloaden
1. Öffnen Sie: `scripts/download-all-assets-complete.js`
2. Kopieren Sie den Inhalt
3. Fügen Sie in die Browser-Konsole ein
4. Ausführen: `downloadAllAssetsComplete()`
5. ✅ Alle Assets werden heruntergeladen

### Schritt 5: Routen & Seiten extrahieren
1. Öffnen Sie: `scripts/extract-all-routes-and-pages.js`
2. Kopieren Sie den Inhalt
3. Fügen Sie in die Browser-Konsole ein
4. Ausführen: `extractAllRoutesAndPages()`
5. ✅ Alle Routen werden extrahiert

### Schritt 6: 1:1 Original-Kopie erstellen
1. Öffnen Sie: `scripts/create-1-1-original-copy.js`
2. Kopieren Sie den Inhalt
3. Fügen Sie in die Browser-Konsole ein
4. Ausführen: `create1To1OriginalCopy()`
5. ✅ Komplette Kopie-Struktur wird erstellt

## 🔧 NACH DER EXTRAKTION

### 1. Assets organisieren
- Kopieren Sie alle heruntergeladenen Dateien in die richtigen Ordner
- JavaScript → `assets/javascript/`
- CSS → `assets/css/`
- Bilder → `assets/images/[kategorie]/`

### 2. HTML anpassen
- Öffnen Sie `original-html-source.html`
- Passen Sie alle Asset-Pfade an lokale Pfade an
- Testen Sie die Datei

### 3. Komplett testen
- Öffnen Sie die lokale HTML-Datei
- Prüfen Sie ob alles funktioniert
- Prüfen Sie ob das Design 1:1 ist
