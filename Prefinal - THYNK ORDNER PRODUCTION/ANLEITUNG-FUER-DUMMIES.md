## 🎯 WAS IST DAS?

**THYNK ORDNER** ist ein **einfaches Bestellsystem** das **direkt in Ihrem Browser** läuft. 
**KEIN Server nötig, KEINE Installation, einfach öffnen und loslegen!**

---

## ✅ SCHNELLSTART (3 SCHRITTE)

### Schritt 1: Datei öffnen
1. Öffnen Sie die Datei **`thynk-order-local.html`** mit Ihrem Browser
   - Einfach **Doppelklick** auf die Datei
   - Oder Rechtsklick → "Öffnen mit" → Browser wählen

### Schritt 2: Bestellung erstellen
1. Geben Sie ein Produkt ein (Name, Preis, Menge)
2. Klicken Sie auf **"➕ Zum Warenkorb"**
3. Geben Sie Kundendaten ein (Name, E-Mail, Adresse)
4. Klicken Sie auf **"✅ Bestellung erstellen"**

### Schritt 3: Fertig!
- Ihre Bestellung wird gespeichert
- Sie sehen alle Bestellungen in der Liste
- Alles funktioniert **lokal** - keine Internet-Verbindung nötig!

---

## 📋 DETAILLIERTE ANLEITUNG

### Neue Bestellung erstellen:

1. **Produkt hinzufügen:**
   - **Produktname:** z.B. "iPhone 15"
   - **Preis:** z.B. "999.99" (in Euro)
   - **Menge:** z.B. "1"
   - Klicken Sie auf **"➕ Zum Warenkorb"**
   - Wiederholen Sie das für alle Produkte

2. **Kundendaten eingeben:**
   - **Name:** z.B. "Max Mustermann"
   - **E-Mail:** z.B. "max@example.com"
   - **Adresse:** z.B. "Musterstraße 123"

3. **Bestellung abschließen:**
   - Klicken Sie auf **"✅ Bestellung erstellen"**
   - Fertig! Bestellung wird gespeichert

---

### Bestellungen verwalten:

#### Bestellung ansehen:
- Klicken Sie auf **"👁️"** neben einer Bestellung
- Sie sehen alle Details

#### Status ändern:
- Klicken Sie auf **"✏️"** neben einer Bestellung
- Wählen Sie neuen Status:
  - **1** = pending (ausstehend)
  - **2** = paid (bezahlt)
  - **3** = shipped (versendet)
  - **4** = cancelled (storniert)

#### Bestellung löschen:
- Klicken Sie auf **"🗑️"** neben einer Bestellung
- Bestätigen Sie die Löschung

---

### Daten sichern:

#### Exportieren:
1. Klicken Sie auf **"💾 Daten exportieren"**
2. Eine JSON-Datei wird heruntergeladen
3. Diese Datei können Sie aufbewahren oder weitergeben

#### Importieren:
1. Klicken Sie auf **"📥 Daten importieren"**
2. Wählen Sie eine exportierte JSON-Datei
3. Alle Bestellungen werden geladen

---

## ❓ HÄUFIGE FRAGEN

### Wo werden die Daten gespeichert?
- **Im Browser** (localStorage)
- Nur auf Ihrem Computer
- Nicht im Internet!

### Kann ich die Daten verlieren?
- Ja, wenn Sie:
  - Den Browser-Cache löschen
  - Den Browser wechseln
  - Den Computer wechseln
- **Lösung:** Regelmäßig exportieren!

### Funktioniert es ohne Internet?
- **JA!** Alles läuft lokal
- Internet ist nur nötig zum Öffnen der Datei (einmalig)

### Kann ich es auf einem anderen Computer nutzen?
- Ja! Exportieren Sie die Daten
- Kopieren Sie die HTML-Datei
- Importieren Sie die Daten auf dem anderen Computer
