```powershell

- Öffne die konfliktbehafteten Dateien

- LÖse Konflikte manuell

- Dann:

Dann pushen

git push -u origin main ``` ---

⚠️ WARNUNG: Force Push lÖscht alle Dateien im Remote-Repository! ```powershell
