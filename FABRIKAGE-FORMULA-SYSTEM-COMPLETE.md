## 📐 FORMEL-ZU-PROGRAMM PROZESS

### Einzelne Formel → Programm:

1. **Formel auswählen:**
   - Wähle eine Formel aus der Datenbank

2. **Programm generieren:**
   - `generateProgramFromFormula(formulaId)`
   - Generiert JavaScript-Code aus Formel

3. **Programm exportieren:**
   - Export als .js Datei
   - Kann direkt verwendet werden

### Formeln mischen → Programm:

1. **Formeln auswählen:**
   - Wähle 2+ Formeln aus der Liste

2. **Formeln mischen:**
   - `mixFormulas([formulaId1, formulaId2, ...])`
   - Erstellt gemischte Formel

3. **Programm generieren:**
   - Generiert Code aus gemischter Formel
   - Kombiniert Funktionalitäten

4. **Programm exportieren:**
   - Export als .js Datei
