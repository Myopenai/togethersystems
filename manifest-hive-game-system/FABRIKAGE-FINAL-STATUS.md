## 🚀 QUICK START

### Installation
```bash
cd manifest-hive-game-system
npm install
```

### Datenbank
```bash
createdb manifest_hive
psql manifest_hive < database/schema.sql
```

### Server
```bash
npm run dev
```

### Docker
```bash
docker-compose up -d
```
