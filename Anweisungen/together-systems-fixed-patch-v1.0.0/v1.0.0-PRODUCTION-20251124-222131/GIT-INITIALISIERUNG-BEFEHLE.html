🔧 TROUBLESHOOTING

Problem: "remote origin already exists"

```powershell git remote remove origin git remote add origin https://github.com/DEIN-USERNAME/togethersystems-portal.git ```

Problem: "Authentication failed"

- Verwende Personal Access Token statt Password - Token erstellen: https://github.com/settings/tokens - Scopes: `repo` (vollstÄndiger Zugriff)

Problem: "Workflow not found"

- PrÜfe ob `.github/workflows/deploy.yml` existiert - PrÜfe: `git add .github/workflows/deploy.yml` - PrÜfe: `git commit -m "Add GitHub workflow"` ---
