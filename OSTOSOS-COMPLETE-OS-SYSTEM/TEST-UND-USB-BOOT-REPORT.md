## 🎯 FUNKTIONSWEISE

### Test-Suite:
1. Öffne `OSTOSOS-ERWEITERTE-TESTS.html` im Browser
2. Klicke auf "🚀 Alle Tests starten"
3. Tests laufen automatisch durch
4. Ergebnisse werden angezeigt:
   - ✅ Bestanden
   - ❌ Fehlgeschlagen
   - ⚠️ Warnung (normal bei file://)
5. Zusammenfassung zeigt:
   - Anzahl bestandener Tests
   - Anzahl fehlgeschlagener Tests
   - Pass-Rate in Prozent

### USB-Boot-Creator:
1. Öffne `OSTOSOS-USB-BOOT-CREATOR.html` im Browser
2. Wähle Image-Typ (ISO/IMG/ZIP)
3. Klicke auf "🚀 Boot Image erstellen"
4. Warte bis Image erstellt ist
5. Klicke auf "💾 Image herunterladen"
6. Folge der Anleitung für deine Plattform:
   - **Windows:** Rufus verwenden
   - **macOS:** Disk Utility + Terminal (dd)
   - **Linux:** fdisk + dd oder Etcher
7. Konfiguriere BIOS für USB-Start
8. Starte Computer neu - OSTOSOS startet automatisch
