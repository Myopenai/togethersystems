## 🚀 Verwendung

### Build-Varianten auswählen
1. Öffne `BUILD-VARIANTEN-AUSWAHL.html` im Browser
2. Wähle deine bevorzugte Variante
3. Klicke auf "Ausgewählte Variante starten"

### HTML/JavaScript Variante
```
Öffne OSTOSOS-OS-COMPLETE-SYSTEM.html im Browser
```

### Python One-File Variante
```bash
# Web UI
python osotosos.py

# CLI Dashboard
python osotosos.py --cli

# Mit Theme
python osotosos.py --theme high_contrast

# Developer Mode
python osotosos.py --dev
```
