Sicherheit & Verifikation

ℹ️ Was ist das?

Hier prüft das System die Sicherheit. Eine Hash‑Kette ist eine Kette von Prüfsummen - wenn eine fehlt, wurde etwas manipuliert. Key‑Rotation bedeutet, dass alte Schlüssel durch neue ersetzt werden. Compliance prüft, ob alles den Regeln entspricht. Einfach auf "Hash‑Kette prüfen" klicken - das System macht den Rest.

Netzwerk & Mesh

ℹ️ Was ist das?

Mesh bedeutet, dass Geräte sich direkt verbinden - ohne Server dazwischen. P2P (Peer-to-Peer) ist die direkte Verbindung zwischen zwei Geräten. HMAC ist ein Sicherheitscode zur Verifizierung. Presence zeigt, ob jemand online ist. Einfach auf "P2P aktivieren" klicken - das System verbindet sich automatisch.

Offline‑First & Service Worker

ℹ️ Was ist das?

Offline‑First bedeutet, dass alles auch ohne Internet funktioniert. Ein Service Worker ist ein Hintergrundprogramm, das Daten speichert. Cachen bedeutet, dass Daten lokal gespeichert werden. Einfach auf "Offline aktivieren" klicken - das System speichert alles automatisch.
