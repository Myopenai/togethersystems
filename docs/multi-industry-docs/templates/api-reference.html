API Overview

This is the complete reference documentation for our Multi-Industry API. The API follows REST principles and uses JSON for request and response bodies.

Base URL

https://api.togethersystems.com/v1

Content Type

All API requests should include the following header:

Content-Type: application/json

Authentication

All API requests must include an API key in the Authorization header.

Request Headers

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

Getting an API Key

To get an API key, log in to your dashboard and navigate to the API section.

Rate Limiting

API requests are limited to 1000 requests per hour per API key.

Rate Limit Headers

X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 995
X-RateLimit-Reset: 1679999999

E-commerce API

Products

GET
/ecommerce/products
List all products

Example Request

curl -X GET https://api.togethersystems.com/v1/ecommerce/products \
  -H "Authorization: Bearer YOUR_API_KEY"

Example Response

{
  "data": [
    {
      "id": "prod_123",
      "name": "Premium T-Shirt",
      "price": 29.99,
      "stock_quantity": 100
    }
  ],
  "pagination": {
    "total": 1,
    "page": 1,
    "per_page": 25
  }
}

Insurance API

Claims

POST
/insurance/claims
Submit a new claim

Example Request

curl -X POST https://api.togethersystems.com/v1/insurance/claims \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "policy_number": "POL123456",
    "incident_date": "2025-01-15T10:30:00Z",
    "description": "Water damage to living room"
  }'

Error Handling

All error responses follow the same format:

{
  "error": {
    "code": "invalid_request",
    "message": "The request is missing a required parameter",
    "details": {
      "parameter": "amount"
    }
  }
}

Common Error Codes

Code HTTP Status Description
invalid_request 400 The request is missing a required parameter or is otherwise malformed
unauthorized 401 Authentication failed or user doesn't have permissions
not_found 404 The requested resource doesn't exist
rate_limit_exceeded 429 Too many requests
server_error 500 An internal server error occurred
