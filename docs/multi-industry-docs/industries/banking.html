Getting Started

Onboarding Process

  1. Register your application in the Developer Portal
  2. Obtain API credentials (Client ID and Secret)
  3. Configure IP whitelisting and redirect URIs
  4. Implement OAuth 2.0 authentication flow
  5. Start making API calls in sandbox environment
# Get your API key first
curl -X POST https://api.togethersystems.com/oauth2/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d 'grant_type=client_credentials&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET'
const axios = require('axios');

async function getAccessToken() {
  const response = await axios.post('https://api.togethersystems.com/oauth2/token', 
    'grant_type=client_credentials',
    {
      auth: {
        username: 'YOUR_CLIENT_ID',
        password: 'YOUR_CLIENT_SECRET'
      },
      headers: {
        'Content-Type': 'application/x-www-form-urlencoded'
      }
    }
  );
  return response.data.access_token;
}
import requests

def get_access_token():
    url = 'https://api.togethersystems.com/oauth2/token'
    data = {'grant_type': 'client_credentials'}
    response = requests.post(
        url,
        data=data,
        auth=('YOUR_CLIENT_ID', 'YOUR_CLIENT_SECRET')
    )
    return response.json()['access_token']

Authentication

OAuth 2.0 Flow

Our API uses OAuth 2.0 with PKCE for secure authentication. Follow these steps to authenticate:

1

Request Authorization

Redirect users to the authorization endpoint to grant permissions.

GET /oauth2/authorize?response_type=code&client_id=YOUR_CLIENT_ID
  &redirect_uri=YOUR_REDIRECT_URI&state=RANDOM_STRING&scope=transactions:read,accounts:read
2

Exchange Code for Token

Exchange the authorization code for an access token.

POST /oauth2/token
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code&code=AUTH_CODE
&redirect_uri=YOUR_REDIRECT_URI&client_id=YOUR_CLIENT_ID
3

Use Access Token

Include the access token in the Authorization header of your API requests.

GET /v1/accounts
Authorization: Bearer YOUR_ACCESS_TOKEN
Important: Never expose your client secret in client-side code. Use server-side authentication for production applications.
