# 🚀 OSTOSOS - START FÜR ALLE PLATTFORMEN

## ✅ VERFÜGBARE START-SCRIPTS:

### Windows (.bat)
**Datei:** `OSTOSOS-START.bat`
**So verwenden:**
- Doppelklick auf `OSTOSOS-START.bat`
- Funktioniert auf Windows

### Linux (.sh)
**Datei:** `OSTOSOS-START.sh`
**So verwenden:**
```bash
chmod +x OSTOSOS-START.sh
./OSTOSOS-START.sh
```
Oder Doppelklick (je nach Desktop-Umgebung)

### macOS (.command oder .sh)
**Datei:** `OSTOSOS-START.command` oder `OSTOSOS-START.sh`
**So verwenden:**
- Doppelklick auf `OSTOSOS-START.command`
- Oder im Terminal: `./OSTOSOS-START.sh`
