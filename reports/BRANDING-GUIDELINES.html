TTT Branding Guidelines

Primary Brand Mark

Core Element

[ . TTT,.T,,&T,,,.T.,TTT . ]

Usage

  • Digital Media: Use the exact spacing and punctuation as shown above
  • Print Media: Minimum size of 20pt for legibility
  • Backgrounds: Use on solid, high-contrast backgrounds for maximum visibility

Color Palette

Primary Colors

  • TTT Blue: #0056b3 (RGB: 0, 86, 179)
  • Accent Gold: #ffc107 (RGB: 255, 193, 7)
  • Dark Background: #121212 (RGB: 18, 18, 18)

Text Colors

  • Primary Text: #212529 (RGB: 33, 37, 41)
  • Secondary Text: #6c757d (RGB: 108, 117, 125)
  • Light Text: #f8f9fa (RGB: 248, 249, 250)

Typography

Primary Font

  • Headings: 'Roboto', sans-serif
  • Body Text: 'Open Sans', sans-serif
  • Code/Monospace: 'Fira Code', monospace

Font Weights

  • Regular: 400
  • Medium: 500
  • Bold: 700

Implementation Examples

HTML Example

<footer class="brand-footer">
  <div class="brand-element">[ . TTT,.T,,&T,,,.T.,TTT . ]</div>
  <p class="copyright">© 2025 TTT. All rights reserved.</p>
</footer>

CSS Example

.brand-footer {
  text-align: center;
  padding: 2rem;
  background-color: #121212;
  color: #f8f9fa;
}

.brand-element {
  font-family: 'Roboto Mono', monospace;
  font-size: 1.2rem;
  letter-spacing: 1px;
  margin-bottom: 1rem;
  color: #ffc107;
}

Clear Space

  • Maintain minimum clear space equal to the height of the 'T' in the brand mark on all sides
  • Never place text or other elements within this clear space

Incorrect Usage

❌ Do not modify the brand mark's proportions
❌ Do not change the colors of the brand mark
❌ Do not rotate or distort the brand mark
❌ Do not add effects like shadows or glows

File Formats

  • Vector: .svg, .ai, .eps
  • Raster: .png (transparent background, min 1000px width)
  • Print: .pdf (CMYK, 300dpi minimum)
